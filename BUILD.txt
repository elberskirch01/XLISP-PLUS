To build:

Linux (64bit Ubuntu 24):

	cd sources
	make -f makelx64
	
Windows, VS (2022/2026) with X64_X86 Cross Tools:
	cd source
	nmake -f makevswin32
	or for console:
	nmake -f makevs32stdio
	
Windows, VS (2022/2026) with X64 Native Tools:
	cd source
	nmake -f makevswin64
	or for console:
	nmake -f makevs64stdio
	

Note:
touch is used also in Makefile for MS Visual Studio, but is not part of the community release. But it can obtained e.g. from GNU Win32 Tools.

See also the original build.txt.
